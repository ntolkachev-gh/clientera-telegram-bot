# 🚀 Оптимизированная база знаний для Qdrant

Эта папка содержит оптимизированную структуру базы знаний салона LALIQ Beauty Studio для эффективной работы с векторной базой данных Qdrant.

## 📁 Структура папки

### Файлы данных (чанки)
- `contact_and_booking.md` - Контакты и информация о записи
- `specialists_info.md` - Информация о специалистах салона
- `services_*.md` - Услуги по категориям (маникюр, брови, ресницы, косметология, волосы, депиляция, инъекции)
- `pricing_overview.md` - Обзор цен по категориям
- `retail_products.md` - Продукты для продажи

### Служебные файлы
- `chunks_mapping.json` - Метаданные о структуре чанков
- `load_to_qdrant.py` - Скрипт для загрузки в Qdrant
- `requirements.txt` - Python зависимости
- `QDRANT_STRUCTURE.md` - Документация по структуре данных
- `USAGE_EXAMPLES.md` - Примеры использования поиска
- `README.md` - Этот файл

## 🔧 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск Qdrant

#### Docker (рекомендуется):
```bash
docker run -p 6333:6333 -v $(pwd)/qdrant_storage:/qdrant/storage qdrant/qdrant
```

#### Или скачать бинарник:
```bash
# Скачайте с https://github.com/qdrant/qdrant/releases
./qdrant --web-ui
```

### 3. Загрузка данных

```bash
python load_to_qdrant.py
```

Скрипт автоматически:
- ✅ Создаст коллекцию `laliq_knowledge_base`
- ✅ Загрузит все чанки с метаданными
- ✅ Протестирует поиск
- ✅ Выведет статистику

## 🔍 Возможности поиска

### Семантический поиск
```python
# Поиск по смыслу, а не по точным словам
search_knowledge_base("как попасть к мастеру")
# Найдет информацию о записи, даже если слово "запись" не упоминается
```

### Фильтрация по метаданным
```python
# Только услуги с ценами
filter = {"key": "has_prices", "match": {"value": True}}

# Услуги конкретного специалиста
filter = {"key": "specialist", "match": {"value": "sevil_bammatova"}}

# Ценовой диапазон
filter = {"key": "price_range.max", "range": {"lte": 3000}}
```

### Категории поиска
- **contact_info** - Контакты и запись
- **specialists** - Информация о мастерах
- **services** - Услуги с ценами
- **pricing** - Ценовые категории
- **retail** - Товары для продажи

## 🎯 Примеры запросов

```python
# Информация о записи
search_booking_info("телефон для записи")

# Поиск услуг по цене
search_services_by_price("маникюр", max_price=2000)

# Поиск по специалисту
search_by_specialist("что делает Севиль", "севиль")

# Умный поиск с контекстом
smart_search("сколько стоит наращивание")
```

```bash
curl http://localhost:6333/collections/laliq_knowledge_base
```

### Тестовый поиск:
```bash
curl -X POST http://localhost:6333/collections/laliq_knowledge_base/points/search \
  -H "Content-Type: application/json" \
  -d '{"vector": [0.1, 0.2, ...], "limit": 3}'
```

## 🔄 Обновление данных

Для обновления базы знаний:

1. Отредактируйте нужные `.md` файлы
2. Запустите `python load_to_qdrant.py`
3. Скрипт обновит изменившиеся чанки

Или полная перезагрузка:
```bash
curl -X DELETE http://localhost:6333/collections/laliq_knowledge_base
python load_to_qdrant.py
```
