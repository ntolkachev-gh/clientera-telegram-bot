## Рекомендации по оптимизации чанков

### Группа 1: Контактная информация и запись
**Объединить в один чанк:**
- Номер телефона
- Процесс записи
- Рекомендации по записи
- Общая информация о салоне

### Группа 2: Специалисты
**Объединить в один чанк:**
- Список специалистов с ID
- Их специализации
- Услуги каждого специалиста

### Группа 3: Услуги по категориям (отдельные чанки)
- Маникюр и уход за руками
- Брови
- Ресницы
- Косметология
- Парикмахерские услуги
- Депиляция
- Инъекционная косметология
- Другие услуги

### Группа 4: Ценовая информация
**Объединить в один чанк:**
- Общая статистика цен
- Группировка по ценовым категориям

### Группа 5: Ритейл
**Отдельный чанк:**
- Уходовая косметика
- Декоративная косметика
- Бренды и продукты
