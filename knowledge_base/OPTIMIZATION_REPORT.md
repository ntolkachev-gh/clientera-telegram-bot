## Преимущества оптимизированной структуры

### 🎯 Для векторного поиска
- **Релевантность:** Каждый чанк сфокусирован на конкретной теме
- **Размер:** Оптимальный для embedding (не слишком большой/маленький)
- **Контекст:** Сохранен смысловой контекст в рамках темы

### 🔧 Для обслуживания
- **Дублирования:** Полностью устранены
- **Консистентность:** Единый источник правды для каждой информации
- **Обновления:** Легче поддерживать актуальность

### 🤖 Для ИИ-ассистента
- **Точность:** Меньше противоречивой информации
- **Скорость:** Быстрее находит нужную информацию
- **Качество:** Более релевантные ответы клиентам

## Рекомендации по загрузке в Qdrant

### Метаданные для каждого чанка
```json
{
  "chunk_id": "services_manicure",
  "category": "services",
  "service_type": "manicure",
  "size": "large",
  "keywords": ["маникюр", "ногти", "гель-лак"],
  "specialist": "any",
  "price_range": "390-3890"
}
```

### Стратегия индексации
1. **Основной поиск:** По содержимому чанка
2. **Фильтрация:** По метаданным (категория, тип услуги, ценовой диапазон)
3. **Бустинг:** Приоритет для контактной информации при вопросах о записи

### Параметры векторизации
- **Модель:** Рекомендуется multilingual embedding model
- **Размер вектора:** 768 или 1024 измерения
- **Дистанция:** Cosine similarity
