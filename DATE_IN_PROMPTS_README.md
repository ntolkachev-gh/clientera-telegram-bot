# Автоматическое добавление текущей даты в системные промпты

## Описание

Реализована функциональность автоматического добавления текущей даты, времени и дня недели в системные промпты приложения. Это помогает ИИ-ассистенту понимать контекст времени при обработке запросов клиентов.

## Что добавлено

### 1. Автоматические переменные даты

При форматировании системных промптов автоматически добавляются следующие переменные:

- `{current_date}` - текущая дата в формате YYYY-MM-DD
- `{current_time}` - текущее время в формате HH:MM
- `{current_day}` - текущий день недели на русском языке

### 2. Поддерживаемые промпты

Автоматическое добавление даты работает для следующих промптов:

- `salon_assistant_system` - системный промпт салонного ассистента
- `booking_analysis` - анализ запросов на бронирование
- `fact_extraction` - извлечение фактов из разговоров

### 3. Возможность переопределения

Дату можно переопределить вручную, передав соответствующие параметры:

```python
formatted_prompt = format_prompt(
    PromptNames.SALON_ASSISTANT_SYSTEM,
    favorite_services="стрижка",
    current_date="2024-12-25",
    current_day="Среда",
    current_time="10:00"
)
```

## Техническая реализация

### Изменения в `prompts/__init__.py`

- Добавлен импорт модуля `datetime`
- Модифицирована функция `format_prompt()` для автоматического добавления даты
- Добавлен словарь русских названий дней недели

### Изменения в промптах

Все системные промпты теперь начинаются с блока:

```
ТЕКУЩАЯ ДАТА И ВРЕМЯ
Сегодня: {current_date} ({current_day})
Текущее время: {current_time}
```

### Исправления форматирования

Исправлены фигурные скобки в описаниях API функций и примерах (заменены на `{{` и `}}`), чтобы избежать конфликтов с Python-форматированием.

## Примеры использования

### Автоматическое добавление даты

```python
from prompts import format_prompt, PromptNames

# Дата добавится автоматически
prompt = format_prompt(
    PromptNames.SALON_ASSISTANT_SYSTEM,
    favorite_services="стрижка, окрашивание"
)
```

### Ручное переопределение даты

```python
# Кастомная дата для тестирования
prompt = format_prompt(
    PromptNames.SALON_ASSISTANT_SYSTEM,
    favorite_services="стрижка",
    current_date="2024-12-25",
    current_day="Среда"
)
```

## Преимущества

1. **Контекст времени** - ИИ понимает, когда происходит разговор
2. **Автоматизация** - не нужно вручную передавать дату каждый раз
3. **Гибкость** - возможность переопределения для тестирования
4. **Локализация** - дни недели отображаются на русском языке
5. **Консистентность** - все системные промпты имеют одинаковый формат даты

## Совместимость

Изменения обратно совместимы:
- Существующий код продолжает работать без изменений
- Новые переменные даты добавляются автоматически
- Старые параметры промптов остаются без изменений
