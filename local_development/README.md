# Локальная разработка и тестирование

Эта папка содержит файлы и скрипты, используемые для локальной разработки и тестирования.

## Содержимое

### Docker и контейнеризация
- `docker-compose.yml` - Docker Compose конфигурация для локального запуска сервисов
- `docker_manager.py` - Управление Docker контейнерами
- `init.sql` - SQL скрипт инициализации локальной базы данных

### Скрипты запуска
- `start_local.sh` - Запуск локального бота
- `start_web_bot.sh` - Запуск веб-версии бота
- `run_local_test.py` - Запуск локальных тестов
- `run_local_web_with_logs.py` - Запуск веб-бота с логированием
- `run_local_with_logs.py` - Запуск бота с логированием
- `run_bot.py` - Основной скрипт запуска бота
- `run_simple_bot.py` - Запуск упрощенной версии бота
- `simple_bot.py` - Упрощенная версия бота

### Локальные версии бота
- `local_bot_web.py` - Веб-интерфейс для локального бота
- `local_test.py` - Локальное тестирование
- `demo_local_bot.py` - Демо-версия локального бота
- `demo_reminder.py` - Демо напоминаний

### Утилиты и инструменты
- `setup_local_env.py` - Настройка локального окружения
- `clear_ports.py` - Очистка занятых портов
- `quick_start_logs.py` - Быстрый запуск с логами
- `check_config.py` - Проверка конфигурации

### Поиск и работа с базой знаний
- `interactive_search.py` - Интерактивный поиск
- `quick_search.py` - Быстрый поиск
- `quick_test.py` - Быстрое тестирование
- `rebuild_knowledge_base.py` - Перестроение базы знаний
- `update_knowledge_final.py` - Финальное обновление базы знаний
- `update_knowledge_from_api.py` - Обновление базы знаний из API
- `update_qdrant_chunks.py` - Обновление чанков в Qdrant

### Тестирование
- `test_gpt5.py` - Тесты GPT-5
- `test_gpt5_simple.py` - Простые тесты GPT-5
- `test_new_get_services.py` - Тесты получения услуг
- `test_real_yclients_api.py` - Тесты реального API YClients

### Другие файлы
- `.local_bot_web.pid` - PID файл для веб-бота
- `start_demo.py` - Запуск демо

## Использование

Эти файлы предназначены только для локальной разработки и не должны использоваться в production окружении на Heroku.

Для запуска локального окружения:

1. Установите Docker и Docker Compose
2. Запустите `docker-compose up` для поднятия локальных сервисов
3. Используйте соответствующие скрипты для запуска и тестирования

## Примечание

Все production конфигурации и скрипты находятся в корневой директории проекта.
