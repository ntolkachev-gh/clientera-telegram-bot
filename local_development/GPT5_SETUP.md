# Настройка GPT-5 для всех запросов OpenAI

## 🚀 Что было изменено

Проект обновлен для использования **GPT-5** по умолчанию для всех запросов к OpenAI API.

## 📝 Изменения в коде

### 1. Конфигурация (`config.py`)
- Добавлена настройка `openai_default_model: str = "gpt-5"`

### 2. OpenAI клиент (`core/openai_client.py`)
- Все методы теперь используют модель по умолчанию из конфигурации
- Обновлены цены на токены для GPT-5
- Убраны жестко заданные ссылки на `gpt-4`
- **Важно**: GPT-5 не поддерживает параметры `temperature` и `max_tokens`

### 3. README.md
- Обновлена документация для отражения использования GPT-5

## 🔧 Настройка

### Переменные окружения
Добавьте в ваш `.env` файл:

```env
# OpenAI
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_DEFAULT_MODEL=gpt-5  # Модель по умолчанию
```

### Доступные модели
- `gpt-5` - новая модель OpenAI (рекомендуется)
- `gpt-4` - предыдущая версия
- `gpt-4-turbo` - быстрая версия GPT-4

## 💰 Цены на токены

Обновлены цены для GPT-5:
- **GPT-5**: $0.005 за 1000 входных токенов, $0.015 за 1000 выходных токенов
- **GPT-4**: $0.03 за 1000 входных токенов, $0.06 за 1000 выходных токенов
- **GPT-4-turbo**: $0.01 за 1000 входных токенов, $0.03 за 1000 выходных токенов

## ⚠️ Особенности GPT-5

### Поддерживаемые параметры
- ✅ `model` - название модели
- ✅ `messages` - сообщения для диалога
- ✅ `tools` - инструменты для function calling
- ✅ `tool_choice` - выбор инструментов

### НЕ поддерживаемые параметры
- ❌ `temperature` - только значение по умолчанию (1)
- ❌ `max_tokens` - не поддерживается
- ❌ `max_completion_tokens` - не поддерживается

### Автоматическая адаптация
Код автоматически определяет модель и использует соответствующие параметры:
- **GPT-5**: минимальный набор параметров
- **GPT-4/другие**: полный набор параметров

## ⚠️ Важные замечания

1. **Доступность**: Убедитесь, что у вас есть доступ к GPT-5 в OpenAI
2. **Квота**: Проверьте лимиты использования API
3. **Стоимость**: GPT-5 может иметь другие тарифы, чем указано в коде
4. **Fallback**: При ошибках с GPT-5 система может автоматически переключиться на GPT-4

## 🔄 Откат к GPT-4

Если нужно вернуться к GPT-4, измените в `.env`:

```env
OPENAI_DEFAULT_MODEL=gpt-4
```

## 📊 Мониторинг

Все запросы к OpenAI логируются в базу данных с указанием:
- Использованной модели
- Количества токенов
- Стоимости
- Цели использования

## 🎯 Результат

После настройки все запросы к OpenAI будут автоматически использовать GPT-5:
- Чат-запросы
- Извлечение фактов
- Анализ запросов на бронирование
- Function calling с инструментами

GPT-5 обеспечивает более качественные и точные ответы по сравнению с GPT-4.
