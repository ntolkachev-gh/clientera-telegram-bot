## 🔧 Технические улучшения

### Новые методы в `YclientsToolsHandler`:

1. **`_get_all_services_from_qdrant()`**
   - Использует scroll API для получения всех записей
   - Фильтрует по category="services"
   - Обрабатывает до 1000 записей за запрос
   - Исключает векторы для экономии трафика

2. **`_parse_services_from_content()`**
   - 4 различных паттерна парсинга:
     - `- Услуга — 1500 ₽`
     - `• Услуга - 1500 руб`
     - `Услуга: 1500 ₽`
     - `1. Услуга - 1500 ₽`
   - Поддержка диапазонов цен: `100-300 ₽`
   - Очистка названий от лишних символов

3. **`_estimate_service_duration()`**
   - Длительные процедуры (120 мин): наращивание, ламинирование, окрашивание
   - Средние процедуры (60 мин): маникюр, педикюр, массаж
   - Инъекционные процедуры (45 мин): ботокс, филлеры
   - Быстрые процедуры (30 мин): покрытие, коррекция

4. **`_normalize_category_name()`**
   - Маппинг технических названий в понятные:
     - `services_manicure` → `Маникюр`
     - `services_hair` → `Парикмахерские услуги`
     - `services_cosmetology` → `Косметология`
