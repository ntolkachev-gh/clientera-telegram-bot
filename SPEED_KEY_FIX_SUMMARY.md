# 🔧 Исправление ошибки с ключом 'speed'

В логах возникала ошибка `'speed'` при обработке сообщений:
```

2025-08-23T13:00:41.270992+00:00 app[bot.1]: 2025-08-22 00:33:16,989 - core.openai_client - INFO - 🤖 Отправка запроса в OpenAI с tools - Модель: gpt-4o-mini, Клиент: 35

2025-08-23T13:00:41.272383+00:00 app[bot.1]: 2025-08-22 00:33:16,989 - __main__ - ERROR - Ошибка при обработке сообщения: 'speed'
```

## Причина
В словаре `MODEL_SPEED_CHARACTERISTICS` отсутствовал ключ `"speed"` для всех моделей, что приводило к ошибке `KeyError: 'speed'` при попытке получить информацию о модели.

## Исправления

### 1. Добавлен недостающий ключ "speed"
```python
# Было:
MODEL_SPEED_CHARACTERISTICS = {
    "gpt-5": {"avg_response_time": 25.0, "recommendation": "Только для сложных задач"},
    "gpt-4o": {"avg_response_time": 8.0, "recommendation": "Сбалансированный выбор"},
    # ...
}

# Стало:
MODEL_SPEED_CHARACTERISTICS = {
    "gpt-5": {"speed": "slow", "avg_response_time": 25.0, "recommendation": "Только для сложных задач"},
    "gpt-4o": {"speed": "medium", "avg_response_time": 8.0, "recommendation": "Сбалансированный выбор"},
    # ...
}
```

### 2. Безопасное обращение к ключам
```python
# Было:
"speed": MODEL_SPEED_CHARACTERISTICS[model]["speed"]

# Стало:
"speed": model_data.get("speed", "unknown")
```

### 3. Дополнительные проверки
- Проверка типа модели
- Fallback к безопасной модели при ошибках
- Валидация структуры моделей при инициализации

### 4. Улучшенное логирование
- Отладочная информация о моделях
- Предупреждения о некорректных моделях
- Безопасная обработка исключений
